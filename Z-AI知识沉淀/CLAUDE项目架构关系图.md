## 关系说明

| 层级 | 组件 | 职责 | 关系 |
|------|------|------|------|
| **规范层** | CLAUDE.md | 定义项目规范、编码标准、工作流 | 指导所有 Agent 和 Skill |
| **角色层** | .claude/agents/ | 定义 Agent 的权限、职责、工作流程 | 调用 Skills，读写 knowledge |
| **能力层** | .claude/skills/ | 可复用的单一能力单元 | 被 Agent 调用，操作 knowledge |
| **数据层** | knowledge/ | 存储原始数据、分析结果、知识条目 | 被 Skills 读写 |

## 设计原则

### 1. 分层解耦

- **规范层**：全局约束，所有组件遵循
- **角色层**：有状态，负责工作流编排
- **能力层**：无状态，单一职责，可复用
- **数据层**：独立存储，生命周期分明

### 2. Agent vs Skill

| 特性 | Agent | Skill |
|------|-------|-------|
| 状态 | 有状态 | 无状态 |
| 职责 | 工作流编排 | 单一能力 |
| 权限 | 受限配置 | 继承调用者权限 |
| 复用性 | 项目特定 | 跨项目复用 |
| 触发方式 | 用户 @ 提及 | Agent 内部调用 |

### 3. 数据生命周期

```
raw/ (原始数据)     →  保留 7 天
processed/ (分析结果) →  保留 30 天
articles/ (知识条目)  →  长期存储
archive/ (归档)       →  保留 12 个月
```
